## Установка:

### 1. Установка пакеты с composer
```bash
composer install
```

### 2. Скопируйте .env.example -> .env

### 3. Генерация APP_KEY
```bash
php artisan key:generate
```

### 4. Поставтье DB_PASSWORD в .env

### 5. Миграции
```bash
php artisan migrate --seed
```

### 6. Запустить локального сервера:
```bash
php artisan serve
```
